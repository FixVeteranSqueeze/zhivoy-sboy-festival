# Протокол сценарной комнаты Claude

Claude отвечает за варианты содержательной ткани: шутки, мини-рассказы, споры, реплики ведущих, обращения, философские повороты, добрые поступки, микро-комиксы и редакторские альтернативы. SHOW OS остаётся источником структуры и ограничений.

## Обязательный контекст

Перед каждой сессией Claude получает только актуальные версии:

1. `docs/UNIVERSE_BIBLE.md`;
2. `docs/SHOW_OS.md`;
3. `data/universe.ts`;
4. карту песен и их текстов для нужного блока;
5. список уже использованных шуток, предметов и возвратных линий;
6. вопрос выпуска и требуемый тип модуля;
7. JSON Schema `schemas/show-module.schema.json`.

## Размер задачи

Одна генерация — не более пяти модулей одной главы. Claude не пишет сразу весь концерт: это приводит к одинаковому ритму, повторяющимся формулировкам и ложной цельности.

## Три прохода

### 1. Архитектор

Даёт по три коротких концепции на модуль: premise, turn, payoff, связь с соседними песнями. Реплики ещё не пишет.

### 2. Сценарист

После выбора одной концепции пишет черновик, сценическое действие, звук, визуальное сопровождение и возвратный крючок.

### 3. Жёсткий редактор

Ищет пафос, объяснение очевидного, мемность, повтор, жестокость, ложный факт, имитацию реального автора и отсутствие последствий. Возвращает исправленный JSON.

## Правила по типам контента

### Философия

- Начинается с конкретного противоречия героя.
- Не содержит «истина в том, что», «каждый из нас» и готовой морали.
- Оставляет минимум две разумные позиции.
- Не более одной прямой философской фразы за десять минут.

### Юмор

- Источник: характер, правило мира, несоответствие цели и метода.
- Шутка должна раскрывать героя, двигать сюжет или возвращаться позже.
- Не использовать случайные мемы, унижение уязвимых людей и копирование манеры реальных комиков.
- Эмоциональная кульминация получает право на паузу без шутки.

### Интеллект

- Один модуль — один факт или механизм.
- Любое внешнее утверждение попадает в `factCheck` со статусом `pending`.
- Источник проверяет отдельный редактор; Claude не считается источником.
- Вывод короче объяснения и допускает сомнение.

### Доброта

- Действие имеет цену: время, статус, безопасность, контроль, ресурс или признание ошибки.
- Получатель не обязан немедленно прощать или благодарить.
- Поступок физически меняет следующий номер.

### Мотивация

- Никаких обещаний величия и победы над всеми.
- Нужен один маленький повторяемый шаг.
- Герой может не справиться полностью, но делает выбор доступного масштаба.

### Милые моменты

- Милота возникает из заботы, неловкости, масштаба или честной уязвимости.
- Она не превращает героя в игрушку и не отменяет его конфликт.

## Формат ответа

Финальный ответ Claude — массив чистых JSON-объектов без Markdown по схеме `show-module.schema.json`. Черновики и рассуждения хранятся отдельно и не попадают в рендер.

## Редакторская оценка

Каждый модуль получает 0–2 балла:

- существует только в этой вселенной;
- связан с обеими соседними песнями;
- имеет поворот, а не только тему;
- меняет состояние героя или сцены;
- вызывает конкретную реакцию зрителя;
- производим заявленным бюджетом;
- безопасен и оригинален;
- оставляет полезный след для будущего.

Для постановки нужно минимум 13 из 16 баллов и отсутствие критической ошибки по фактам, правам или характеру.

## Базовый запрос Claude

```text
Прочитай приложенный пакет контекста и работай только внутри канона. Для пяти указанных промежутков предложи по три разные концепции контентного модуля. У каждой укажи premise, turn, payoff, связь с предыдущей и следующей песней, цену доброго действия, источник юмора, визуальный формат и уровень стоимости S/M/L. Не пиши готовые реплики до выбора концепции. Не имитируй реальных артистов и комиков. Любое внешнее фактическое утверждение пометь для проверки.
```
