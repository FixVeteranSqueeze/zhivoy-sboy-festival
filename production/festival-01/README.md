# Живой Сбой #01 — производственный пакет

Эта папка хранит только небольшие манифесты и инструкции. Тяжёлые WAV, изображения и видео не попадают в Git.

## Начать с одного трека

```powershell
npm run track:new -- JS01_01_W1 "Название песни"
```

Команда создаст:

- `intake/JS01_01_W1.json` — карточку происхождения и производства;
- `assets/JS01_01_W1/` — локальную папку для WAV, текста и изображений.

После заполнения карточки:

```powershell
npm run festival:check
```

## Имена файлов

- `JS01_01_W1_master.wav`
- `JS01_01_W1_lyrics.txt`
- `JS01_01_W1_cover.png`
- `JS01_01_W1_character.png`
- `JS01_01_W1_manifest.json`

Слот читается так: `JS01` — фестиваль №1, `01` — артист, `W1` — первая волна.

## Что не коммитить

Мастера, черновики, исходники изображений и рендеры остаются в локальной папке `assets` и резервной копии на VPS. В Git сохраняются только код, манифесты, решения и история изменений.
